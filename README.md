# Сайт центра семейного образования «Раса»

Одностраничный адаптивный лендинг по ТЗ от 14.11.2026. HTML + CSS + ванильный JS, без сборки и зависимостей. Формы заявки нет: связаться с центром можно по телефону, указанному в блоке контактов и подвале.

Живая версия: <https://njiijnokiio-debug.github.io/rasa-center/> (GitHub Pages).

## Быстрый запуск

```bash
# из папки сайта
python -m http.server 8000
```

Затем открыть `http://localhost:8000`. Можно открыть и `index.html` двойным щелчком — сайт полностью статический.

## Структура

```
index.html            лендинг: 9 блоков + подвал
privacy.html          политика конфиденциальности (отдельная страница)
styles.css            все стили, палитра и адаптивность
script.js             меню, галерея, cookie-баннер, аналитика
assets/
  logo.png            логотип центра
  apple-touch-icon.png
  og-cover.jpg        картинка для Open Graph (1200×630)
  img/*.jpg           фотографии центра
  fonts/*.woff2       Manrope и Caveat — локально, без Google Fonts
favicon.png
site.webmanifest
robots.txt
sitemap.xml
.htaccess             HTTPS, кэш, сжатие, базовые заголовки безопасности (только Apache)
```

## Что заменить перед публикацией

### 1. Контакты и реквизиты

- телефон `+7 926 366-10-32` и `tel:+79263661032` — по всему сайту (`index.html`, `privacy.html`);
- адрес сайта `https://njiijnokiio-debug.github.io/rasa-center/` — в `index.html` (canonical, OG, JSON-LD), `privacy.html`, `sitemap.xml`, `robots.txt`. При подключении своего домена замените его по всему проекту;
- адрес и время связи — блок 9 и подвал (сейчас «ТСН „Варшана“, Краснодарский край» и пояснение, что точный адрес подскажут по телефону);
- реквизиты оператора персональных данных — в `privacy.html`.

Логотип `assets/logo.png` — из присланного PDF. Если у клиента есть исходник в векторе, замените файл и при необходимости обновите `favicon.png`, `assets/apple-touch-icon.png` и `assets/og-cover.jpg`.

### 2. Яндекс Метрика и цели

1. Вставьте код счётчика перед `</head>` в `index.html`.
2. В `script.js` укажите `CONFIG.metrikaId` (номер счётчика).
3. Создайте в Метрике цели с точными идентификаторами:
   - `phone_click` — клик по любому телефону;
   - `cta_meet` — «Приезжайте познакомиться»;
   - `cta_support` — «Узнать, как поддержать».

Пока `metrikaId: null`, цели не отправляются, а пишутся в консоль браузера — удобно проверять.

### 3. Юридические формулировки

Перед публикацией обязательно согласуйте с юристом клиента (раздел 9 ТЗ):

- «Мы не школа в юридическом смысле. Мы — община, которая учит своих детей»;
- «подготовка к ОГЭ», «ФГОС», «без стресса и репетиторов»;
- просьбы о поддержке и любые будущие реквизиты;
- политику обработки персональных данных и хранение данных в РФ;
- согласие родителей на фото детей.

Тексты блоков взяты из ТЗ дословно, кроме служебных подписей и коротких пояснений (например, «Даты и программу ближайших сборов уточняйте по телефону», «Точный адрес подскажем по телефону»). Их можно убрать или заменить после согласования.

## Редактирование без программиста

Сейчас это статический лендинг: тексты лежат прямо в `index.html` с комментариями по блокам. Для клиента, которому нужно менять тексты и фото самостоятельно, рекомендуются два пути:

- перенести вёрстку в WordPress (ACF-блоки) или Tilda — визуальный редактор без кода;
- оставить статику и передать клиенту короткую инструкцию по правке текста в `index.html`.

Если нужен именно этот дизайн и простая CMS, лучше сразу закладывать WordPress-тему; текущая версия — готовый референс и вёрстка для переноса.

## Проверено

- адаптивность от 320 px до широких экранов;
- клавиатурная навигация, видимый фокус, skip-link, `aria`-атрибуты;
- reduced motion (`prefers-reduced-motion`);
- ленивая загрузка изображений, сжатые JPG, минимум JS;
- шрифты Manrope и Caveat подключены локально, без запросов к Google Fonts;
- галерея с лайтбоксом, управление стрелками и Esc;
- cookie-баннер с сохранением выбора;
- SEO: title/description, H1–H2, alt, canonical, Open Graph, JSON-LD, sitemap, robots;
- форма заявки удалена, блок контактов сохранён.

## Деплой на GitHub Pages

Сайт уже опубликован: <https://njiijnokiio-debug.github.io/rasa-center/>.

1. Репозиторий: `https://github.com/njiijnokiio-debug/rasa-center`, ветка `main`.
2. Настройки Pages: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Чтобы обновить сайт, сделайте коммит и пуш в `main` — Pages пересоберётся автоматически.
4. Для собственного домена: **Settings → Pages → Custom domain**, затем DNS-запись `CNAME` на `njiijnokiio-debug.github.io` и включите HTTPS.
5. После подключения домена замените адрес `https://njiijnokiio-debug.github.io/rasa-center/` в `index.html`, `privacy.html`, `sitemap.xml` и `robots.txt`.
6. `.htaccess` на GitHub Pages не работает — заголовки безопасности и кэширование настраиваются средствами хостинга или CDN.

## Деплой на обычный хостинг

1. Загрузите файлы на хостинг в РФ (HTTPS).
2. Пропишите домен в canonical/OG/sitemap/robots.
3. Настройте SSL и при необходимости включите редирект на HTTPS (блок в `.htaccess`).
4. Прогоните Lighthouse на мобильном, проверьте Safari (iPhone), Chrome, Firefox, Яндекс Браузер, Edge.
5. Подключите Метрику и проверьте цели.
